# 东洋（TOYO）注塑机的 ASCII 通讯协议

**东洋（TOYO）注塑机的 ASCII 通讯协议，通过 TCP Socket 传输**。代码注释标明与 ToyoMonitor 使用同款协议。

具体实现：

| 项目     | 内容                                                         |
|:---------|:-------------------------------------------------------------|
| 传输方式 | TCP，客户端主动连接机台并轮询                                |
| 默认端口 | `8200`，可通过 `toyo.ascii.port` 配置                        |
| 请求报文 | `":",35,C0\r`                                                |
| 应答格式 | `":",36,<CSV数据>,校验\r`（按代码注释）                      |
| 帧结束符 | 回车 `\r`                                                    |
| 点位解析 | 根据 `toyo/points.csv`，将地址 `B.N` 映射到 CSV 下标 `1 + N` |

因此，这里的 **ASCII 指东洋设备文本协议，并非 Modbus ASCII**。
当前实现读取整帧后按逗号拆分取值，没有实现响应校验码验证。
